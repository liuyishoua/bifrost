# 页面切换体验

2026-10-01：改善通过公网访问抖音工作台时各菜单切换的等待感。

- 点击导航后立即显示目标页面，不等待公共账号列表请求完成。
- 搜索入库与用户管理先使用浏览器内存中的账号列表，后台刷新；更新下拉框时保留仍有效的当前选择。
- 用户管理先显示筛选区，标签与用户列表并行加载，标签更新保留当前勾选。
- 总览、任务、对话详情、标签、话术和账号页按需加载各自数据，移除切页前多余的账号请求。等待数据时提供加载反馈。
- 快速切页后，旧响应及失败提示不能覆盖新页面，旧页面不得重新启动轮询。
- 搜索、任务操作、扫码与入库继续使用已有接口和后端校验；本次不修改后台执行和鉴权逻辑。
- 更新前端静态文件后浏览器刷新即可生效，不需要重启业务进程。
